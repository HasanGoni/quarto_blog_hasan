MACaQ: Fast, Model Agnostic Calibrated Quantization for Low-Precision Weights and Activations

arXiv 2611.10649 · picked for the week of 2026-11-13 · Introduces a fast, model-agnostic quantization method (MACaQ) that can significantly reduce inference costs for deploying small local VLMs in real-time industrial settings.

arXiv HF paper page Code

MACaQ is a post-training quantization method that converts neural network weights and activations to 4-bit precision (MXFP4) by treating each linear layer independently. It achieves lower perplexity than prior methods like DuQuant++ and MR-GPTQ while requiring up to 11x less quantization time, with only a 2.3% inference overhead on large models.

Explain it like I'm a data scientist

The primary gap in low-precision quantization is that existing methods often require propagating basis transforms across layers to avoid runtime overhead. This creates complex inter-layer dependencies, making the process architecture-specific and computationally expensive during quantization. MACaQ addresses this by keeping transforms local to each linear layer, eliminating the need to modify neighboring layers or propagate transformations through the network.

The method works by applying a per-channel scale and a block-Hadamard transform to activations online, while absorbing the inverse transforms into the weights offline. This allows for a streaming quantization process where only one layer resides in memory at a time. A Hessian-aware coordinate-descent procedure called Flip-Refinement then optimizes the 4-bit codes by greedily moving them to adjacent representable values, improving upon simple round-to-nearest quantization.

Accumulate layer input statistics from calibration data

Forward hooks are used to collect the input activations for each linear layer during a calibration pass. These inputs are used to compute the Hessian matrix, which captures the importance of each weight for the layer's output.

Calculate and apply per-channel scales to balance magnitudes

A scale factor is computed for each channel to suppress outliers in activations and balance the weight columns. This scaling is applied to the activations online and absorbed into the weights offline.

Apply block-Hadamard rotation to distribute energy

A block-diagonal Hadamard transform is applied to the scaled activations and the inverse is absorbed into the weights. This spreads out concentrated channel energy, making the data more Gaussian-like and easier to quantize.

Select optimal block exponents via Hessian-weighted search

For each block of 32 elements, candidate exponents are evaluated to minimize the Hessian-weighted reconstruction error. The best exponent is selected and held fixed for the subsequent refinement step.

Optimize FP4 codes using Hessian-aware coordinate descent

Starting from a round-to-nearest assignment, individual FP4 codes are moved to adjacent levels if it reduces the reconstruction error. This process iterates until no further improvements are found or a maximum iteration count is reached.

Pack refined codes into MXFP4 format

The final refined FP4 codes and selected block exponents are packed into the MXFP4 format. The original layer is replaced by this quantized version, ready for inference.
