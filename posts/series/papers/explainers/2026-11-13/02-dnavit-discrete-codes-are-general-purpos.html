dNaViT: Discrete Codes are General-Purpose Visual Representations

arXiv 2611.12426 · picked for the week of 2026-11-13 · Investigates discrete codes as general-purpose visual representations, which is highly relevant for unifying vision and language in small VLMs like LFM2-VL and Qwen3-VL for efficient defect analysis.

arXiv HF paper page

dNaViT is a visual tokenizer that converts images into discrete codes, similar to how language models use text tokens. It uses a frozen encoder with residual modulation and grouped product quantization to preserve both semantic meaning and pixel-level detail. The paper claims this approach allows a single discrete vocabulary to handle understanding, generation, and editing tasks effectively.

Explain it simply

Explain it like I'm five

Imagine you have a magic box that turns pictures into a secret code made of little blocks. Usually, computers need different boxes for looking at pictures and drawing new ones. But this magic box uses one special code for everything. It keeps the big ideas of the picture, like 'that is a dog,' and the tiny details, like the color of its fur. It does this by adding extra clues to the picture before turning it into blocks. Then, it can turn those blocks back into a perfect picture or use them to understand what is in the image. It is like having one universal language for all your visual toys.

Explain it like I'm a data scientist

The core problem is that visual models typically use continuous representations for understanding and separate latents for generation, creating a fragmented infrastructure. Discretizing vision into tokens offers a unified path but faces an information bottleneck where high-level semantics and fine-grained pixel details conflict within a limited vocabulary. Existing methods struggle to balance these opposing requirements without sacrificing performance in either domain.

dNaViT addresses this by using a frozen pretrained encoder and a Residual Modulator (ResMod) that injects reconstruction-aware cues into semantic features via a zero-initialized residual path. It employs Grouped Product Quantization to scale discrete capacity without increasing sequence length, followed by dual-branch supervision. One branch aligns codes with semantic features, while the other reconstructs pixels using a combination of MSE, LPIPS, and perceptual losses, ensuring the discrete codes retain both abstract meaning and visual fidelity.

Discrete Autoregressive Modeling
Like predicting the next word in a sentence based on the previous ones. A method where models predict the next item in a sequence from a fixed set of options, used here to treat visual tokens like text tokens.
Residual Modulator (ResMod)
Like adding a filter to a photo to bring out hidden details without changing the main subject. A module that fuses intermediate features from a frozen encoder and applies a learned scale-and-shift correction to enrich semantic features with pixel-level detail.
Grouped Product Quantization
Like describing a color by combining a hue, brightness, and saturation code rather than one giant unique number. A technique that splits feature channels into groups and quantizes each group separately to expand the codebook capacity without increasing the spatial sequence length.
Dual-Branch Reconstruction
Like checking a map for both the city names (semantics) and the street textures (pixels) to ensure it's accurate. A training strategy where the same discrete codes are decoded by two separate branches: one for semantic feature alignment and one for pixel-level image reconstruction.
Frozen Pretrained Encoder
Using a trusted, unchangeable camera lens to capture the base image before adding effects. A vision transformer whose weights are kept fixed during training to preserve its original semantic capabilities while new modules learn to add detail.
LPIPS
Measuring how much two pictures look different to a human eye, not just mathematically. A perceptual similarity metric based on VGG features used to supervise the pixel reconstruction branch for visual fidelity.

Extracting multi-level features from the frozen vision transformer

The input image is processed by a frozen pretrained vision transformer. Spatial tokens from various layers are selected to capture information at different levels of abstraction, from low-level details to high-level semantics.

Enriching semantic features with reconstruction-aware details via ResMod

The Residual Modulator fuses the selected intermediate features and predicts a zero-initialized scale-and-shift residual. This reorganizes the geometry of the semantic features to accommodate reconstruction-relevant information without compromising the original semantic structure.

Converting enriched features into discrete codes using grouped product quantization

The modulated features are split into channel groups, and each group is quantized using its own learned codebook. This creates a tuple of discrete indices for each spatial position, scaling the discrete capacity while keeping the spatial grid unchanged.

Aligning discrete codes with continuous semantic features

The quantized embeddings are fed into a semantic decoder that maps them back to the continuous feature space. This branch is supervised by a loss combining feature regression and cosine alignment to ensure the codes retain the pretrained semantic structure.

Reconstructing high-fidelity images from discrete codes

The same quantized embeddings are passed to a pixel decoder that restores the spatial grid and generates the image. This branch is trained with multiple losses, including MSE, LPIPS, and perceptual losses, to ensure the reconstruction matches the original image in both structure and detail.

Training the system to balance semantic and pixel-level information

The model undergoes progressive training that coordinates the dual-branch objectives. This process suppresses gradient interference between the semantic and pixel reconstruction tasks, allowing the discrete codes to serve as a general-purpose representation for both understanding and generation.
