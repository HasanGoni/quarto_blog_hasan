Open Vision Banana: A Fully Open Recipe for Generative Visual Perception

arXiv 2611.15844 · picked for the week of 2026-11-13 · Provides a fully open recipe for generative visual perception, offering concrete techniques for leveraging pretrained image generators for vision tasks that can be adapted for defect detection and localization.

Open Vision Banana (OVB) is a fully open recipe for turning public image generators into multi-task perception models by rendering predictions as RGB images. It outperforms the proprietary Vision Banana on Cityscapes segmentation and rivals state-of-the-art depth estimators using only public data.

Explain it simply

Explain it like I'm five

Imagine you have a magic paintbrush that can draw pictures. Usually, it just draws fun things like cats or cars. But this paper teaches the paintbrush to draw special pictures that tell us secrets about the world, like how far away things are or what color a specific object is. The trick is that the paintbrush draws the answer in colors, and then a computer reads those colors to understand the picture. It’s like using a secret code where red means 'car' and blue means 'sky'. The researchers made this magic paintbrush free for everyone to use. They also found a way to make it even better by asking it to draw the same picture many times and voting on the best answer.

Explain it like I'm a data scientist

The gap in current research is that while proprietary models like Vision Banana show that image generators can perform visual perception tasks, their data, weights, and code are closed, making it impossible to understand which design choices drive performance. OVB addresses this by providing a fully reproducible pipeline using open-weight FLUX.2-Klein models and public datasets, isolating the impact of color encoding, prompt design, and parameter adaptation.

The method works by framing perception tasks (segmentation, depth, normals) as conditional image editing. The model generates an RGB image where specific colors or intensities encode the prediction (e.g., a specific RGB triplet for a class, or brightness for inverse depth). A deterministic readout module then converts this generated image back into a standard prediction format. A key innovation is 'legend ensembling,' a test-time scaling technique that generates multiple predictions with different random color legends and fuses them via majority vote to correct unstable color-class bindings without retraining.

Jargon buster (each with a daily-life picture)

Legend Ensembling
Like asking five friends to color-code a map with different color schemes and then voting on which color belongs to which country to fix mistakes. A test-time scaling method that segments an image under several random class-color legends and fuses the results by majority vote to improve accuracy.
Rectified-Flow
Like smoothing out a crumpled piece of paper into a flat sheet by following a straight path. The training objective used for the base generator, which predicts the velocity field to transform noise into the target image.
Affine-Invariant Depth
Like measuring how far away a friend is by comparing their size to yours, without needing to know the exact distance in meters. A depth encoding where values are normalized per image so that relative distance is preserved, allowing evaluation after per-image alignment.
mIoU
The percentage of the pizza slice that matches the slice you ordered, averaged over all the different toppings. Mean Intersection over Union, a standard metric for segmentation that measures the overlap between predicted and ground-truth masks.
Zero-Shot
Taking a test on a topic you never studied in class, relying only on your general knowledge. Evaluating the model on datasets that were completely excluded from its training data, testing its ability to generalize to unseen benchmarks.
Color Binding
Mixing up which crayon you use for the sky and which for the grass, even though you know what they are. The error where the model correctly identifies a region but assigns it the wrong color from the prompt, leading to incorrect class labels.

Constructing the training mixture from public sources

The pipeline mixes perception data for segmentation, depth, and normals with replay data from text-to-image and editing datasets. This creates pools of 2.1M to 3.8M training pairs, ensuring the model retains its generative abilities while learning perception tasks.

Rendering annotations as RGB target images

Deterministic encoders convert ground-truth annotations into RGB images. For segmentation, classes are painted in random colors; for depth, inverse depth is mapped to brightness; for normals, vector components map to RGB channels. This allows the use of a standard image generation objective.

Fine-tuning open-weight generators with flow matching

FLUX.2-Klein 4B and 9B models are fine-tuned using a rectified-flow objective. All transformer parameters are trained, while the VAE and text encoder remain frozen. Geometry tasks use a validity mask to exclude undefined regions from the loss calculation.

Generating perception outputs as images

Given an input image and a prompt specifying the task and color legend, the model generates an RGB image. This image contains the visual representation of the prediction, such as colored masks for segmentation or a depth map.

Converting RGB images to task-specific predictions

A deterministic decoder reads the generated image back into a prediction. For segmentation, pixels are assigned to the nearest prompted color. For depth, the image is mapped back to inverse depth and aligned. This step bridges the gap between the generated image and the final metric.

Applying legend ensembling for test-time scaling

The model generates multiple predictions with different random color legends. The resulting class maps are fused by per-pixel majority vote. This corrects unstable color-class bindings and improves mIoU without any retraining.
