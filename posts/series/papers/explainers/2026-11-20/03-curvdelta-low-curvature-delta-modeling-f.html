CurvDelta: Low-Curvature Delta Modeling For Surgical Learning and Unlearning

arXiv 2611.24654 · picked for the week of 2026-11-20 · CurvDelta offers a method for fine-tuning models while preserving general capabilities, addressing the catastrophic forgetting risk when adapting small VLMs to specific industrial tasks.

arXiv HF paper page

CurvDelta is a framework for adapting large language models that ensures new capabilities or unlearning do not degrade existing general knowledge. It achieves this by constraining parameter updates to a 'low-curvature' space derived from the local geometry of the preservation loss, using Kronecker-factored approximate curvature (K-FAC) for scalability.

Explain it simply

Explain it like I'm five

Imagine you have a toy robot that knows how to walk and dance. If you teach it a new trick, it might forget how to walk. CurvDelta is like a special training mat that only lets the robot move in safe directions. It looks at how the robot moves when it is happy and healthy. Then, it builds a path that keeps the robot safe while it learns the new trick. This way, the robot learns the new thing but still knows how to walk and dance. It is like learning to ride a bike without forgetting how to walk.

Explain it like I'm a data scientist

The core problem in LLM adaptation is the capability preservation trade-off: fine-tuning for a specific task (like math or code) or unlearning sensitive data often degrades general capabilities. Existing methods like replay or gradient projection either fail to guarantee the preservation constraint or impose indirect constraints that lead to unfavorable trade-offs between task performance and retention.

CurvDelta addresses this by formulating adaptation as a constrained optimization problem where the preservation loss is bounded. It constructs a low-curvature delta space using the local Hessian of the preservation loss around the pre-adaptation model. By approximating this curvature with block-diagonal K-FAC and applying factorwise spectral truncation, it creates a separable projection that restricts updates to directions where the preservation loss changes minimally. This allows for both dense (CurvDelta) and low-rank (CurvLoRA) parameterizations that maintain a favorable acquisition-retention balance.

Estimate preservation curvature using K-FAC on the preservation set

The method first estimates the Kronecker-factored approximate curvature (K-FAC) factors for each adapted linear weight. This is done using the Monte Carlo Fisher estimator on the preservation set $D_{pres}$ at the initial parameters $\theta_0$. These factors capture the local geometry of the preservation loss.

Construct the low-curvature delta space via factorwise spectral truncation

Using the K-FAC factors, the method identifies the trailing eigenspaces (low-curvature directions) by retaining eigenvectors corresponding to small eigenvalues. It defines orthogonal projectors $P^{out}$ and $P^{in}$ that project updates onto this low-curvature subspace, ensuring the update stays within the safe region.

Select the delta parameterization: dense matrix or low-rank factors

The user chooses between CurvDelta (dense delta) or CurvLoRA (low-rank LoRA factors). The trainable parameters are initialized, and the projection is integrated into the parameterization. For CurvLoRA, the projection is applied to the LoRA factors $B$ and $A$ to avoid materializing dense matrices.

Optimize the task loss while keeping base weights and projections fixed

The model is trained by minimizing the task loss $L_{task}$ with respect to the delta parameters. The base weights $\theta_0$ and the projection matrices remain frozen. The optimizer updates the delta parameters, and the applied delta is always projected into the low-curvature space, guaranteeing the preservation constraint is respected throughout training.

Merge the optimized delta into the base model

After training, the final delta parameters are used to compute the applied delta $\Delta W$. This delta is added to the base weights to produce the adapted model. The resulting model has achieved the target task performance while maintaining general capabilities due to the constrained update path.
