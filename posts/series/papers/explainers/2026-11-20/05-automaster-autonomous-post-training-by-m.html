AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher

arXiv 2611.26510 · picked for the week of 2026-11-20 · AutoMaster's Skill-Guided Fine-Tuning provides a structured post-training method to reinforce specific behaviors, useful for refining VLMs on complex defect detection criteria.

arXiv HF paper page Code

AutoMaster is an autonomous post-training system that uses an LLM agent to design natural-language 'skills' that guide a teacher model's behavior during data generation. By fine-tuning student models on these skill-guided trajectories, the system improves performance by 1.42–8.99 percentage points over standard fine-tuning on successful unguided trajectories, demonstrating that shaping teacher behavior makes the same model a more effective teacher.

Explain it simply

Explain it like I'm five

Imagine you have a friend who is good at solving puzzles but sometimes takes silly shortcuts. Instead of just showing you their finished puzzles, you give them a special note that says, 'Check your work carefully!' When they solve the puzzles with that note, they do a better job of showing *how* they think. You then watch them solve the puzzles with the note and learn from their careful steps. This helps you become a better puzzle solver than if you had just watched them rush through it. The computer does this by writing its own helpful notes for the teacher computer. It then teaches the student computer using those careful examples. The result is a student computer that is smarter and more careful than before.

Explain it like I'm a data scientist

The core problem is that standard supervised fine-tuning (SFT) on successful agent trajectories reinforces not only the correct actions but also undesirable habits like unsupported assumptions or superficial verification, which persist even in successful runs. Furthermore, desirable behaviors may be underrepresented in unguided rollouts, meaning that task success alone does not specify which behaviors should be reinforced for optimal student learning.

AutoMaster addresses this by introducing Skill-FT, where an LLM agent designs natural-language skills to suppress bad habits and elicit effective behaviors during teacher rollouts. The agent operates in nested loops: an inner loop tests and refines these skills on pilot rollouts to select high-quality demonstrations, while an outer loop fine-tunes the student model and uses evaluation feedback to guide further skill refinement. Crucially, the skill instructions are retained in the training input, which the paper finds supports better behavioral internalization than removing them, even though the student is evaluated without these skills.

Jargon buster (each with a daily-life picture)

Supervised Fine-Tuning (SFT)
Like a student copying a teacher's homework to learn the method, rather than just listening to a lecture. A training method where a model is updated using labeled examples (trajectories) to mimic the desired behavior.
Trajectory
A step-by-step video recording of how someone solved a problem, including every click and thought. The sequence of actions, observations, and reasoning steps an agent takes to complete a task.
Rollout
Running a simulation of a game to see how it plays out from start to finish. The process of generating a complete trajectory by interacting with the task environment.
Skill
A sticky note with a specific tip, like 'always double-check your math,' placed on the teacher's desk. A natural-language instruction appended to the system prompt to guide the teacher's reasoning and actions.
Teacher Model
The expert who demonstrates the task, whose work is used to train the student. The larger or more capable LLM that generates the training data (trajectories) for the student model.
Student Model
The learner who watches the expert's demonstrations and tries to copy their skills. The target model (e.g., Qwen3.5-4B/9B) that is fine-tuned on the teacher's trajectories.
Vanilla SFT
Learning from the expert's work without any special hints or corrections, just copying what they did. Standard fine-tuning on successful trajectories generated by the teacher without any skill-guided behavioral shaping.

The agent examines initial trajectories to find bad habits and missing behaviors.

The LLM agent reviews tasks and initial rollouts from both the unguided teacher and the initial student. It identifies undesirable habits to discourage and useful behaviors that are underrepresented, even on tasks the teacher already solves. This analysis guides the design of the initial skills.

The agent crafts specific instructions to shape the teacher's reasoning.

Based on the analysis, the agent designs natural-language skills that specify how to reason or act in relevant situations. These skills are intended to suppress undesirable habits and elicit effective behaviors that are rare in unguided rollouts. The skills are appended to the system prompt for the teacher.

The agent tests candidate skills to ensure they elicit intended behaviors.

The agent runs pilot rollouts with the teacher using the new skills. It examines the resulting trajectories to see if the skills work as intended without introducing new problems. If issues are found, the agent refines the skill instructions or their scope of application.

Promising skills are applied to larger batches of tasks.

Once skills are refined, the agent scales them up to batched rollouts across the training task pool. The teacher generates trajectories guided by these skills. The agent also considers unguided trajectories that already exhibit useful patterns.

The agent selects high-value trajectories for fine-tuning.

The agent reviews the generated trajectories and selects those it judges valuable for training. This selection considers both task outcomes and the demonstrated behaviors. The selected trajectories, including the skill instructions in the input, form the training set for the next step.

The student model is fine-tuned on the curated demonstrations.

The student model is fine-tuned using standard SFT on the selected trajectories. The skill instructions are retained in the training input to help the student internalize the behaviors. The training starts from the same initial checkpoint in every round.

The agent uses evaluation results to guide the next iteration.

The fine-tuned student is evaluated on benchmarks without the generated skills. The agent analyzes the scores and trajectories to see if the intended behaviors appear and which weaknesses persist. This feedback informs whether to revise skills, change task coverage, or select different demonstrations in the next outer-loop round.
