AltRA-Test: An Alternative Annotator Test for LLM Judges Without Shared Annotators

arXiv 2611.26073 · picked for the week of 2026-11-20 · AltRA-Test provides a statistical framework for validating LLM judges, which is critical for the user's auto-label verification and judging workflows.

arXiv HF paper page

The paper introduces ALT RA-TEST, a statistical method to determine if Large Language Models (LLMs) can replace human annotators without requiring the same humans to label every item. It uses a bootstrap resampling technique to compare the agreement between human-only and mixed human-LLM panels, establishing that the test is consistent and asymptotically valid.

Explain it simply

Explain it like I'm five

Imagine you have a box of colored blocks and you want to know if a robot can pick them out as well as your friends do. Usually, you need the same friends to look at every single block to be fair. But what if different friends look at different blocks? This new test lets you check if the robot is good enough even when the friends are mixed up. You take a handful of blocks, let the robot guess one color, and see if the group still agrees on the colors. If the robot makes the group agree less, it might not be ready to help. If the group still agrees well, the robot is a good helper. This helps us know when we can let the robot do the work.

Explain it like I'm a data scientist

The primary gap addressed is that existing statistical tests for LLM-as-a-judge, such as ALT-TEST and STT, require a dense annotation setting where the exact same set of annotators labels every item in the evaluation set. This assumption fails in common large-scale scenarios like crowdsourcing or preference annotation, where items are labeled by different subsets of annotators, rendering these tests inapplicable to a significant portion of real-world datasets.

ALT RA-TEST solves this by employing a paired percentile bootstrap that resamples items with replacement and draws a fixed number of human annotations ($k$) for each item without relying on annotator identities. It constructs a mixed panel by substituting one human annotation with the LLM's prediction and tests whether the inter-annotator agreement (IAA) of this mixed panel is non-inferior to the all-human panel. By using an adaptive margin proportional to observed human disagreement, the test accommodates both objective and subjective tasks, providing a statistically grounded decision on whether the LLM preserves the shared signal among human annotators.

Prepare the annotated dataset and test parameters

The process begins with a dataset of items, each having multiple human annotations, and an LLM that provides a single annotation per item. The researcher specifies the panel size $k$, the margin constant $c$, and the number of bootstrap iterations $B$. This setup ensures the test can handle items labeled by different subsets of annotators.

Resample items and draw human annotation panels

In each bootstrap iteration, the algorithm samples $N$ items with replacement from the dataset. For each sampled item, it draws $k$ human annotations without replacement from the available pool. This step creates a synthetic dataset that mimics the original structure but allows for statistical estimation of variability.

Construct human-only and mixed human-LLM panels

For each sampled item, a human-only panel is formed from the $k$ drawn annotations. A mixed panel is then created by replacing one random human annotation in the panel with the LLM's annotation for that item. This substitution simulates the effect of replacing one human annotator with the LLM.

Calculate inter-annotator agreement for both panels

The algorithm computes the agreement score $R$ (e.g., Krippendorff’s α) for both the human-only matrix and the mixed matrix. These scores quantify the reliability of the annotation panels, with higher values indicating greater consensus among the annotators in each configuration.

Compute the adjusted substitution gap

The difference in agreement between the mixed and human-only panels is calculated as the substitution gap. An adaptive margin, proportional to the human disagreement, is added to this gap. This adjustment accounts for the inherent noise in the task, allowing for a small, acceptable loss in agreement due to the LLM substitution.

Determine if the LLM passes the non-inferiority test

The empirical quantile of the adjusted gaps across all bootstrap iterations is compared to zero. If the quantile is positive, the null hypothesis that the LLM reduces agreement by more than the margin is rejected. This indicates that the LLM is a statistically valid alternative to a human annotator.
