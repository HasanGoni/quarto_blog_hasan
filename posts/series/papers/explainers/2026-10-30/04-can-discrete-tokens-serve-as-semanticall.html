Can Discrete Tokens Serve as Semantically Lossless Representations of Visual Signals?

arXiv 2610.37662 · picked for the week of 2026-10-30 · Investigates the semantic loss in discrete visual tokens, providing insights into optimizing the visual encoder architecture for small VLMs to maintain high-fidelity defect representation.

arXiv HF paper page Code

The paper challenges the assumption that quantizing visual features into discrete tokens causes unavoidable semantic loss. It introduces Factorized Vector Quantization (FVQ), which uses parallel codebooks to maintain high semantic fidelity, allowing discrete models to match continuous ones in multimodal understanding tasks.

Explain it simply

Explain it like I'm five

Imagine you have a big, colorful picture. Usually, if you try to save it using only a few colors, it looks blurry and you lose important details. But this paper shows that if you use a clever way to pick those colors, you can keep the picture looking sharp. It’s like packing a suitcase: if you fold your clothes smartly, you can fit more in without making a mess. The researchers found that the number of 'color choices' you have matters more than how perfect each single choice is. By giving the computer more choices, it can understand the picture just as well as if it had the original. This means we can use simple, digital 'words' to describe pictures without losing the meaning.

Explain it like I'm a data scientist

The central problem is the belief that discrete visual tokens suffer from inherent semantic loss due to quantization error, which limits their utility in multimodal models compared to continuous representations. The authors demonstrate that reconstruction error is a poor proxy for semantic fidelity; instead, the effective bit budget is the key determinant of performance. However, existing multi-codebook methods like RVQ and PQ saturate at high bit budgets because later codebooks receive less informative residuals or narrower channel groups.

Jargon buster (each with a daily-life picture)

Quantization Error
Like the difference between the exact shade of a sunset and the closest color on a limited palette. The distortion introduced when mapping continuous feature values to a finite set of discrete codes.
Bit Budget
The total amount of 'ink' you are allowed to use to describe a picture. The total number of bits used to represent a visual patch, calculated as the number of codebooks multiplied by the log of the codebook size.
Codebook
A dictionary of specific colors or shapes that the model can choose from. A finite set of vectors (codewords) used to approximate continuous features during quantization.
Residual Vector Quantization (RVQ)
Fixing a rough sketch by adding finer details in layers, where each layer fixes the mistakes of the previous one. A method where subsequent codebooks quantize the error (residual) left by the previous codebooks, leading to diminishing returns at high budgets.
Tight Frame
A set of cameras placed around an object so that every angle is covered equally well, with no blind spots. A mathematical property ensuring that the combined projections of a feature preserve its geometry and energy, allowing for exact reconstruction before quantization.
Semantic Fidelity
How well a summary captures the main points of a story, rather than just the exact words. The degree to which a representation retains the information necessary to answer questions or understand the content of the visual signal.

Projecting features into fixed-dimensional views

The visual feature vector is projected into multiple fixed-dimensional views using dense matrices. These projections are constrained to form a tight frame, ensuring that the views collectively preserve the original feature's geometry without biasing any direction.

Quantizing views with symmetric codebooks

Each projected view is independently quantized by finding the nearest codeword in its corresponding codebook. This parallel approach assigns symmetric roles to all codebooks, avoiding the diminishing information flow seen in residual methods.

Reconstructing features via tight-frame synthesis

The selected codewords are combined using a synthesis operator to reconstruct the original feature. Because the analysis and synthesis operators form a tight frame, this reconstruction is exact before quantization, meaning all distortion comes solely from the quantization step.

Training the visual tokenizer

The quantizer is trained to reconstruct frozen visual features from the VFM encoder. This stage learns the codebooks and projections to minimize reconstruction error while maintaining the structural properties of FVQ.

Aligning discrete tokens with language

The tokenizer and LLM are frozen while new visual token embeddings are optimized. This aligns the discrete visual indices with the language embedding space, allowing the LLM to interpret the visual tokens.

Fine-tuning for multimodal understanding

The LLM, visual token embeddings, and merger are jointly optimized on large-scale multimodal data. The tokenizer remains frozen, ensuring that the discrete representation's semantic capacity is fully utilized in downstream tasks.
