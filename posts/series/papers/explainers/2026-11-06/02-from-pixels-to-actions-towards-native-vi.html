Explain it simply

Explain it like I'm five

Imagine you are trying to catch a ball. Usually, a robot looks at the ball through a special filter that squishes the picture into a tiny, blurry dot before it thinks. This paper says that squishing the picture too early makes it hard to see exactly where the ball is. Instead, NEO-VLA looks at the picture like you do, keeping the details sharp all the way through. It lets the robot peek at the picture at different stages, like looking at a sketch and then the final painting. This helps the robot know exactly how to move its arm. Because it keeps the details, it can catch the ball even if the lights change or the camera shakes.

Explain it like I'm a data scientist

Standard Vision-Language-Action (VLA) models rely on a fixed visual encoder (like CLIP or DINOv2) to compress images into a static feature vector before the language model processes them. This abstraction often discards fine-grained spatial and geometric cues critical for precise manipulation, creating a bottleneck where action policies cannot access the evolving visual hierarchy during computation.

NEO-VLA eliminates this separate encoder by using a lightweight convolutional patch embedder to project raw pixels directly into the backbone's token space. A flow-matching action expert then reads cached keys and values from configurable subsets of backbone layers, allowing it to draw from both early, fine-grained visual features and later, semantic representations. This structural change enables the policy to leverage the full computational depth of the visual processing, resulting in superior performance under distribution shifts and frozen-backbone settings compared to encoder-based counterparts.

Converting raw pixels into backbone tokens

The system uses a lightweight two-stage convolutional embedder to map raw image pixels directly into the backbone token space. This produces one visual token for each 32x32 image region, bypassing any separate vision encoder or autoencoder.

Processing visual and language tokens jointly

Visual tokens, text instructions, and robot state tokens are processed together within the 40-layer decoder backbone. Modality-aware attention allows visual tokens to interact bidirectionally while text follows causal attention, enabling co-evolution of representations.

Selecting backbone layers for action readout

The action expert is configured to read cached keys and values from a specific subset of backbone layers (e.g., early, late, or mixed). This makes the depth of visual information access an explicit architectural choice rather than a fixed endpoint.

Predicting continuous actions via flow matching

The action expert attends to the selected backbone layers and noisy action tokens to predict a velocity field. It models the transformation from Gaussian noise to the target action chunk, covering arm joints, end-effector motion, and body movements.

Solving the learned flow for execution

During inference, the system solves the learned flow from time 0 to 1 using 10 Euler steps while keeping the prefix key-value cache fixed. The resulting continuous action chunk is de-normalized and sent to the robot for execution.
