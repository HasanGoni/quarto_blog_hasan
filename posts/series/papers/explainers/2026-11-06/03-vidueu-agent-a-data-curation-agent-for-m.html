VidUEU-Agent is an automated pipeline that converts raw videos into high-quality instruction data for multimodal understanding, editing, and unified tasks. Explain it like I'm a data scientist

The primary bottleneck in advancing unified multimodal models (UMMs) is the scarcity of high-quality, task-oriented instruction data derived from dynamic video sources. While raw videos offer rich temporal and causal information, they are noisy, redundant, and unstructured, making direct conversion into training data difficult. Existing methods often rely on static images or lack the structured verification needed to ensure data reliability and controllability for complex tasks like editing and unified reasoning.

VidUEU-Agent addresses this by implementing a four-stage automated pipeline: global perception to filter low-quality shots, keyframe mining using tool-based signals and VLM checks, metadata construction with consistency filtering, and instruction synthesis routed by task type. The agent autonomously iterates the data distribution based on downstream training feedback, balancing capabilities, domains, and task types. This process yields VidUEU-100K, a dataset of 100K samples that, when used for fine-tuning, demonstrates consistent gains in understanding, editing, and unified multimodal capabilities across multiple benchmarks.

Parsing videos into shots and chapters with quality gating

The agent uses PySceneDetect to split videos into shots and generates summaries at shot, chapter, and video levels. It then applies Gate A to filter out low-quality shots based on informativeness and image quality rules, ensuring only viable content proceeds to the next stage.

Sampling frames and selecting keyframes via tool planning

For retained shots, the agent samples frames and applies Gate B to filter low-quality ones. It performs hierarchical tool planning to collect targeted signals, scores frames based on these signals and summaries, and uses weighted facility-location greedy selection to pick high-quality, non-redundant keyframes.

Generating transitions and clip summaries from keyframes

The agent performs specialized checks on multimodal signals bound to keyframes to mitigate noise. It generates transitions describing changes between consecutive keyframes and a clip summary, verifying the factuality of the text against the signals before binding them into a metadata list.

Synthesizing instruction samples with quality filtering

Gate C filters metadata based on information content and coherence. The agent routes each metadata entry to suitable task types (understanding, editing, unified) and matches instruction templates, requiring the model to cite signal IDs to improve traceability and produce high-quality instruction data.

Autonomously updating data distribution based on training results

The agent trains models on subsets of data, evaluates them on benchmarks, and reflects on weaknesses. It updates the target distribution over capabilities, domains, and task types, adjusting sampling strategies in perception, mining, and synthesis to optimize the final dataset balance and quality.
